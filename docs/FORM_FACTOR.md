# Configurable form-factor study

Duo Studio is an independent browser-hosted design study, not an official Apple product simulator. Its default reference displays use the original prototype's assumed inner/outer proportions (1068 × 751 and 466 × 678 logical units); the Device lab permits custom dimensions. The displayed 7.6-inch/5.4-inch labels and pixel references are design fixtures, not physical-device measurements or a claim of a verified shipping hardware specification.

The expanded form factor is treated as one continuous canvas. App-level work/inspector panes are independent of shell-level two-app allocation. Folding changes allocation and navigation without reconstructing the mounted document or media node. Book/Tabletop are manually selected design explorations; no native posture sensor is simulated by overriding browser APIs.

Use two surfaces for a task and its context, not merely a larger version of a phone screenshot: CAD beside dimensions, profile beside generated geometry, a sequencer beside its mixer, film beside edit settings, document beside its outline, worksheet beside analysis, slide beside notes. A paired compact layout exposes one active app and its pane navigation rather than compressing four unusable panes.

Version 2 adds original creative tools and system test fixtures. See `CREATIVE_OS.md` for workflows and `TESTING_V2.md` for what was actually exercised. Legacy app names identify local interface studies, not native application ports or connections to their online services.
