# Implementation references and provenance

The simulator shell, ten creative applications, engines, procedural media and PWA icons are original source in this repository. The ten everyday studies use third-party product names for identification; they do not embed native binaries, credentials or service clients. No third-party font files are included.

Primary browser/format specifications relevant to the implementation:

- WebGPU and WGSL: https://www.w3.org/TR/webgpu/ and https://www.w3.org/TR/WGSL/
- Web Audio: https://www.w3.org/TR/webaudio/
- MediaStream Recording: https://www.w3.org/TR/mediastream-recording/
- Screen Capture: https://www.w3.org/TR/screen-capture/
- IndexedDB: https://www.w3.org/TR/IndexedDB/
- Service Workers: https://www.w3.org/TR/service-workers/
- Office Open XML: https://ecma-international.org/publications-and-standards/standards/ecma-376/

These are normative references, not claims that this small implementation supports every feature of each specification. Refer to `FORMATS_V2.md` for the implemented subsets and limits. Hardware dimensions/postures are configurable design assumptions; this repository does not establish product-announcement or physical-device claims.
